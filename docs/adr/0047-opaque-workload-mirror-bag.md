# Opaque Workload Mirror bag

**Mirror** (and singular **Workload Setup** materialize) places each Environment Workload onto Host Volume `workloads/<basename>/`. Discovery is every immediate non-hidden Environment directory (ADR-0033) — not gated on `manifest.json`. The Environment-tree portion remains an opaque recursive upsert (`cp -a` semantics: hidden entries included, symlinks preserved as links) for Manifest, Binding, and any inline Artifact bytes. Mirror also resolves Manifest **Source** and applies **Provides** `directories` onto that Host tree (fail closed on reserved collisions including `persist`), so materialize works **regardless of Source** — not Environment-bag upsert alone (ADR-0053). Mirror does not filter siblings or enforce full definition-tree shape beyond Source/Provides rules; consumers stay selective on known siblings. Manifest absence/invalidity fail-closes at **Workload Setup** (and thus **Deploy**), not at discovery; Source resolution failures fail closed in Mirror. One projection rule: Setup materializes the same Host tree Mirror would, then applies Intent. Nested **Persist** under the owner tree survives Mirror/ensure (ADR-0054).

**Amends:** ADR-0041 (retires allowlisted Mirror siblings and `manifest.json` discovery for Mirror / Orphan Reap / `ensure-workloads`).

**Amended by ADR-0054 / #215 / #218:** Host path is `workloads/<basename>/` with nested Persist (retired `internals/workloads` + `data/workloads`).

**Rejected:** Keep Mirror allowlist (false contract; fought operator-owned trees and broke full-tree SoT noop when extras like `www/` existed); soft-skip Manifest-less dirs in batch Setup (second discovery rule; weakens **Deployed**); dereference or refuse symlinks at Mirror; strip in-tree dot entries (breaks paths like `.well-known`); recurse consumer gather/unit install into nested declaration dirs; leave zip/Source materialize to Workload Setup alone (ADR-0053 — Mirror owns Host materialize regardless of Source).
