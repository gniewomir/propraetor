# Workload Intent modes and Purge

The Workload Manifest carries a **Workload Intent** (naming: ADR-0017; thin Manifest + authored Quadlets: ADR-0024): **run**, **stop**, or **trash**. **run** — operator-authored Quadlets up; Route Declarations present in Workload SoT when authored (zero Routes valid); Edge Component Setup gathers and fulfills Intent-**run** Routes — HTTP semantics are whatever those fulfilled fragments declare. **stop** — those Quadlets stopped; Route Declarations are not offered for Edge fulfillment (Edge default miss after Edge Setup re-gather, not a Propraetor 503); Workload data and Domain-scoped certificates preserved. **trash** — same Route-declaration expectation as **stop**; Workload data retained until **Purge**, which permanently deletes every Workload whose Intent is **trash** and Workload-associated data (Host Volume trees under `internals/workloads/<basename>/` and `data/workloads/<basename>/` including Mirrored SoT such as `routes/` / `quadlets/` / `systemd/`, unit files named in that SoT, that Workload’s Platform User EnvironmentFile tree under `~/.config/platform/workloads/<basename>/`, and Setup-owned Environment Configuration drop-ins for its `quadlets/*.container` units — ADR-0035) — not Domains or Domain-scoped certificates (ADR-0022). Purge does not write Edge Route interior; Edge Component Setup re-gather drops previously fulfilled Routes when SoT is gone (ADR-0040). Purge never touches Workloads whose Intent is **run** or **stop**. ACME want-list is Domain assignment (ADR-0023), not Manifest claims — Setup and Purge do not rebuild it.

**Intent stop drops Edge fulfillment via Edge Setup (no Propraetor 503):** process lifecycle parks without Propraetor-owned Edge HTTP shells (Edge default miss — ADR-0022 / ADR-0040); Domain/certs stay.

**Intent trash + Purge over immediate delete on Manifest edit:** makes removal explicit and batchable.

**Amended by ADR-0041:** **Purge** remains Intent-**trash** only (names still in the Environment). Host Workloads absent from the Environment are removed by **Orphan Reap**, not Purge. **Mirror** upserts Environment Workload trees and leaves orphans alone.
