# Workload Provides, Requires, Binding, and Source

Workloads still bind to many Domains, but an external Artifact must not encode Propraetor FQDNs or Environment Configuration bag key names while still attaching to Edge and receiving env. Propraetor splits portable **Artifact** contracts (**Provides** + **Requires** + content) from Environment-placed Propraetor-internal **Workload Manifest** + **Binding**. Domains and ACME stay Environment-owned (`domains.json` / `acme.json`).

**Manifest** is required `intent`, optional human-only `description`, and required **Source** (`internal` or a public zip URI). No `environment`, `database`, or `name` (basename identity unchanged). **Provides** declares directories to materialize and route fragment paths offered for Edge (descriptions human-only; omit ⇒ absent; no `false`). **Requires** declares process env names (human-only descriptions) and a required `database` boolean. **Binding** fully maps want-list FQDNs → ordered Provides route paths and bag keys → Requires env names — every Provides route in ≥1 FQDN array; every Requires env name exactly one remap RHS; FQDNs ⊆ Domain want-list. **Route** fragments are location-context Edge config from Provides, attached only via Binding; gather/fulfill SoT is **Edge-owned storage**, not Workload-tree `routes/` with FQDN-as-filename. **Mirror** materializes each Environment Workload onto the Host Volume **regardless of Source** (Environment tree upsert + resolve Source + apply Provides directories; fail closed if `manifest.json` / `binding.json` / `provides.json` / `requires.json` already collide at the Host destination — zip Environment trees must not contain `provides.json` / `requires.json`). Zip integrity pinning is deferred (v1 trusts the public URI); non-zip Sources are not v1. External ⊂ internal: same Host Deploy shape after resolve. Workload Setup remaps Environment Configuration from Binding + bag on the operator; full-fulfill against Artifact Requires and the containers gate run on the Host after materialize (zip has no Environment `requires.json`). Clean break (ADR-0018).

**Amends:** ADR-0011, ADR-0014, ADR-0022, ADR-0024, ADR-0028, ADR-0033, ADR-0035, ADR-0040, ADR-0041, ADR-0047, ADR-0049 (Route SoT, Manifest env/db/`source`, Declaration gather inputs, Mirror materialize, Environment Configuration selection).

**Rejected:** FQDN-as-Route-filename as authored SoT; FQDNs or bag names inside the external Artifact; `cert` / ACME mode on Manifest or Binding; partial Binding fulfillment; `false` in Provides directories; Manifest-owned `environment` / `database`; Mirror as Environment bag upsert only.
