# Workload Provides, Requires, Binding, and Source

Workloads still bind to many Domains, but an external Artifact must not encode Propraetor FQDNs or Environment Configuration bag key names while still attaching to Edge and receiving env. Propraetor splits portable **Artifact** contracts (**Provides** + **Requires** + content) from Environment-placed Propraetor-internal **Workload Manifest** + **Binding**. Domains and ACME stay Environment-owned (`domains.json` / `acme.json`).

**Manifest** is required `intent`, optional human-only `description`, and required **Source**: `internal` (Artifact is the Environment Workload directory) or zip (Artifact is zip root after obtain). Zip obtain is a relative `.zip` path under that Workload directory (nested segments allowed; no `.` / `..` segments; no leading `/`; suffix case-folded), or an unauthenticated http(s) zip URI (any host, including loopback — no registry, credentials, or `file://`; suffix case-folded). `internal` stays case-sensitive. After obtain, path and URI share extract. Extract refuses members whose paths are absolute or contain `..`. It peels a single top-level directory when that directory is the **only** archive-root entry (every entry counts — no `__MACOSX` / dotdir exception) **and** that directory contains `provides.json`; otherwise Artifact root stays the archive root. Path obtain must name a regular file (not a symlink) under the Workload directory. A Workload directory may itself be a symlink across Environments. No symlink under a Workload directory may resolve outside it (operator Mirror / Setup fail-early **and** Host materialize, every Workload tree); in-tree symlinks that stay inside remain ADR-0047 opaque upsert — this change does not start a blanket “no symlinks in the tree” rule. Operator Mirror / Setup fail early when a path zip is missing or not a regular file (Source string + file exists; not operator unzip/peel); Host materialize still fail-closes. After path extract the `.zip` remains on the Host tree as Environment bag. No `environment`, `database`, or `name` (basename identity unchanged). **Provides** declares directories to materialize and route fragment paths offered for Edge (descriptions human-only; omit ⇒ absent; no `false`). **Requires** declares process env names (human-only descriptions) and a required `database` boolean. **Binding** fully maps want-list FQDNs → ordered Provides route paths and bag keys → Requires env names — every Provides route in ≥1 FQDN array; every Requires env name exactly one remap RHS; FQDNs ⊆ Domain want-list. **Route** fragments are location-context Edge config from Provides, attached only via Binding; gather/fulfill SoT is **Edge-owned storage**, not Workload-tree `routes/` with FQDN-as-filename. **Mirror** materializes each Environment Workload onto the Host Volume **regardless of Source** (Environment tree upsert + resolve Source + apply Provides directories; fail closed if `manifest.json` / `binding.json` / `provides.json` / `requires.json` already collide at the Host destination — zip Environment trees must not contain `provides.json` / `requires.json`). Zip integrity pinning and zip-bomb quotas are deferred (v1: slip rules + Host disk); non-zip origins are not v1. External ⊂ internal: same Host Deploy shape after resolve. Workload Setup remaps Environment Configuration from Binding + bag on the operator; full-fulfill against Artifact Requires and the containers gate run on the Host after materialize (zip has no Environment `requires.json`). Local zip path is an operator Source, not a test-only adapter. **Acceptance** covers extract via case-local path-zip fixtures generated in the case (no committed `.zip` blob, no standing example zip); **Unit** covers thin URI obtain via loopback HTTP (no Host HTTP server in Acceptance; no separate zip-acceptance repo). Clean break (ADR-0018).

**Amends:** ADR-0011, ADR-0014, ADR-0022, ADR-0024, ADR-0028, ADR-0033, ADR-0035, ADR-0040, ADR-0041, ADR-0047, ADR-0049 (Route SoT, Manifest env/db/`source`, Declaration gather inputs, Mirror materialize, Environment Configuration selection).

**Rejected:** FQDN-as-Route-filename as authored SoT; FQDNs or bag names inside the external Artifact; `cert` / ACME mode on Manifest or Binding; partial Binding fulfillment; `false` in Provides directories; Manifest-owned `environment` / `database`; Mirror as Environment bag upsert only; local zip path as test-only adapter; unscoped / absolute / Host-wide zip paths; `file://` as operator Source; three peer Manifest Source kinds (`internal` vs path vs URI); a separate zip-acceptance repo; always-literal zip root with no peel; peel without sole-wrapper + Provides; `__MACOSX` / hidden archive-root exceptions for peel; stripping the path `.zip` from the Host tree after extract; “public” URI as a routability filter; Acceptance Host HTTP for URI obtain; operator-side unzip/peel as fail-early; standing Environment example zip or committed Acceptance `.zip` blob; zip-bomb uncompressed-size caps in v1; blanket refuse of all in-tree Workload symlinks (ADR-0047 upsert of in-tree links unchanged except no outbound escape).
