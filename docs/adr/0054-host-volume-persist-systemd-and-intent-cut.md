# Host Volume reshape, Persist, unified systemd/, Intent cut

Propraetor’s Host Volume layout, unit authorship, and Workload destroy path are reshaped in one clean cut (ADR-0018): mount contract **`/host-volume`** (still **Substrate** / IHP, not Fabric); owner trees at the mount root (`fabric/`, `components/<name>/`, `workloads/<basename>/`, `host-scripts/`) with optional nested **`persist/`** (Artifact must not ship it; Mirror/ensure preserve it; empty dir auto-created for Workloads and Components); one **`systemd/`** bag per owner (Quadlet sources + native units; after projection ≥1 unit file; internal∪external merge by filename, collide → fail; retire `quadlets/` as a consumer directory); Quadlet install via **directory** symlink farm `~/.config/containers/systemd/<kind-prefixed-id>/` → `{owner}/systemd/` so stock Quadlet resolves `Volume=../persist/…` against Host Volume (never per-file unit symlinks — those keep `unit.Path` under XDG and break relatives); native units **copy** into user systemd; Workload Intent is **`run` | `stop` only**; Host destroy is **Orphan Reap** only (Purge / `trash` retired; wipe-while-keeping-Environment-dir is Escape Hatch at best). Fabric and `host-scripts` get no Persist contract.

**Spike:** Same fixtures on Podman **6.0.2** (machine), **5.8.2** (`quay.io/podman/stable:v5.8.2` / Fedora 42 package — latest 5.x with a runnable `quadlet`; GitHub **5.8.6** has no quadlet artifact), and **5.7.1**: kind-prefixed subdir symlink + `Volume=../persist` → absolute Host Volume binds and `SourcePath` on the volume; `UNIT_DIR/<unit>.container.d/` platform drop-ins merge; per-file unit symlinks resolve relatives under XDG (rejected).

**Rejected:** Fabric-owned `.mount`; compile/rewrite Quadlets into flat XDG; dual-read of `/var/lib/host-volume` + `internals/`/`data/`; directory name `durable/` or `state/` (collide with glossary Durable / State).
