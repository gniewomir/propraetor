# Component Setup and Host Volume layout

**Amended by ADR-0040:** Service Network is **Fabric** (Fabric Setup), not a Component; Edge is the Component on that bring-up path. IHP establishes **Substrate** (including the Host Volume mount); IHP Done asserts Substrate readiness for Fabric Setup — not that Fabric is present. Route fulfillment gather is **Edge Component Setup** (ADR-0040 / refined ADR-0022).

**Amended by ADR-0041:** Host Volume layout becomes `internals/{fabric,components,workloads,host-scripts}` + `data/{fabric,components,workloads}` (retires `components/` + `components_data/`). Fabric and Components ship via separate ensure cogs; **Deploy** / **Mirror** / **Orphan Reap** compose bring-up (see ADR-0041). Historical `components/network` path and combined `ensure-components` Fabric+Component packaging are superseded.

**Amended by ADR-0043:** Component Setup Host contract is `pre-workloads.sh` + `post-workloads.sh` (not a single `setup.sh`); Deploy invokes both slots.

Public Hosts get Fabric then Components only **after** Initial Host Provisioning: IHP produces **Substrate** (engine, Platform User, port floor, Host Volume mount) and does not run Fabric Setup, Component Setup, or install Workloads — putting Setup inside cloud-init was rejected because SSH/copy is unsafe mid-IHP and user_data churn would recreate the Host for every change. Instead, operator-side `internals/ensure-fabric.sh` then `internals/ensure-components.sh` each wait for IHP Done (Substrate), scp/tar-copy their trees onto the Host Volume as root (in-place sync so live bind mounts stay valid), chown to the Platform User, and run **Fabric Setup** (Service Network) or **Component Setup** (Edge) respectively — Host logs use that vocabulary. Success means each Setup leaves its target **in the correct state** (header contract on each Setup script). Workload Setup (thin Manifest → Workload Intent + operator Route Declarations / Quadlets into Workload SoT only; ADR-0011 / ADR-0014 / ADR-0017 / ADR-0022 / ADR-0024) and Purge are separate paths; neither is invoked by ensure, and neither writes Edge Route interior. ensure-components also stages the Domain-derived ACME FQDN list for Edge Setup to install into the Host want-list and reconcile Domain fronts (ADR-0023 / ADR-0028). Edge Component Setup gathers Intent-**run** Route Declarations and installs on-demand ACME (ADR-0015 / ADR-0040).

**Host Volume layout:** mount root `/var/lib/host-volume` stays root-owned; everything under it is Platform User–owned. **Source** (repo mirror, scp-replaced) under `/var/lib/host-volume/internals/`: `fabric/` (Service Network — Fabric Setup), `components/edge/` (Edge Component source including `nginx.conf`, which the container bind-mounts from here), Mirrored `workloads/`, and `host-scripts/` (Host-executable helpers + `lib/`, sourced by Setup — not a Component). Authored units under `quadlets/` and `systemd/` by consumer (shape parity with Workloads; ADR-0034) — Fabric Setup / Component Setup install those into the matching Platform User directories under authored basenames; no `certs/` in the source tree. **Data** (Host/Workload durable bytes) under `/var/lib/host-volume/data/`: `fabric/`, `components/edge/` — at least `routes/` (fulfilled Route fragments), `domains/` (Edge Domain fronts — ADR-0028), `certs/`, and an HTTP-01 webroot for ACME (ADR-0015); Edge Component Setup ensures those data directories exist, gathers Route Declarations into `routes/`, and never deletes Domain-front files it does not own; nginx empty-glob includes need no stub files. Workload Declaration SoT lives under `internals/workloads/<name>/`; Workload durable bytes that must survive Mirror live under `data/workloads/<name>/` (ADR-0041). Quadlet and native user units stay under the Platform User’s home. Durable source on the volume lets Fabric/Component Setup re-run after Host rebuild or Park→Apply without relying on IHP; Teardown removes the volume with the Stack (ADR-0016).

**Rejected:** Setup inside IHP; rsync; operator script named apply/provision (Stack apply / IHP collision); root-owned `internals/` trees (blocks rootless binds); certs under the source mirror; wiping runtime routes on ensure; treating Workloads as Components; treating Service Network as a Component peer of Edge; dual-read of retired `components/` + `components_data/` Host Volume layout (ADR-0018).
