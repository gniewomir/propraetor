# Identity Component gathers resource servers, OIDC clients, and permission grants

Public APIs Bound on a Domain need user-delegated access tokens from a Host-local Identity Provider; co-tenant Workloads on the Service Network do not (ADR-0034). **Identity** is a public-Host Component (idle allowed with zero claimants). Engine is Pocket ID. Propraetor does not invent a second authorization server. Edge stays TLS, ACME, Routes, and Forwarded client identity (ADR-0052) — **not** the JWT verifier. The API Workload verifies Bearer **access** tokens (JWKS, `iss`, `aud`, expiry, permission key in `scope`). Bound ≠ resource server: a site or SPA must load without a Bearer.

A Workload is an Identity claimant only with **Requires** `"identity": true` (peer of `database` / `cache`; ADR-0053). **Resource server:** non-empty **Provides** `permissions` (key → human name; key is the OAuth scope token). Exactly **one** Binding FQDN; `resource` / JWT `aud` is `https://<fqdn>` (no path, trailing slash trimmed). Zero or two+ FQDNs with a catalog fails closed. Permission keys must be unique across Workloads. **OIDC client:** **Requires** `permissions` (same shape) plus **Provides** `"oidc_callback": "/…"` (value is the path). Required keys must all belong to exactly one resource-server catalog; spanning two catalogs fails closed. Client Binding may list many FQDNs; each callback URL is `https://<fqdn>` plus that path. Zero client FQDNs fails closed. Same Workload may be both (Required keys ⊆ own catalog). `identity` with neither catalog nor client keys fails closed. No permissions map on Binding. No logout callback URLs. User groups / client allow-list in the Identity Provider UI are not gathered.

**Gather (Component Setup).** Intent-**run**: upsert Pocket ID API by `resource` (`POST` / list+match; `resource` unique and immutable); `PUT` permissions as a full replace that matches by **key** (UUID stable if the key stays); upsert a **public + PKCE** OIDC client with `id` = Workload basename; `PUT` api-access with permission UUIDs resolved from keys; publish Component-owned bindings under `~/.config/platform/workloads/<basename>/identity/` (not Binding remaps) — resource server: issuer, JWKS URL, `aud`; client: issuer, `client_id`, callback URLs, `resource`, `scope`. Intent **stop** unpublishes that binding and **leaves** Identity interior records (minting while the Workload is down is accepted). Omit Provides `permissions` (still Bound as a site), omit the client Declaration, Binding FQDN gone, or **Orphan Reap**: delete the corresponding Pocket ID API and/or OIDC client. Tokens already minted keep old `scope` strings until `exp`; delete does not revoke. Issuer hostname is an Environment-authored Declaration on the Domain want-list. Identity admin API material is Component admin material (not Environment Configuration). Slot bodies follow Database (ADR-0049 / ADR-0043): fulfillment/publish prefer `pre-workloads`; orphan cleanup in `post-workloads`.

**Amends:** ADR-0053 (Provides gains `permissions` and `oidc_callback`; Requires gains `identity` and optional client `permissions`; Binding: resource server exactly one FQDN); ADR-0040 / ADR-0043 (Identity is a further Declaration-fulfilling Component; Environment-authored issuer hostname beside Domain assignment); ADR-0034 (Service Network stays token-free; this story is public Bound APIs and SPAs only); ADR-0052 (Edge is not the JWT gate).

**Rejected:** Edge JWT verification (option 3); Hydra / Dex as this Identity Provider; inferring a resource server from Bound Routes; one Pocket ID API per alias FQDN; per-key or `*` permission Binding; clients named on the resource-server Artifact; globally unique keys without Binding FQDN on the RS; delete catalog/client on Intent **stop**; surgical permission HTTP (Pocket ID only offers full replace-by-key); CIMD or Pocket ID UI as v1 client registration; logout callback gather; user groups; Requires boolean `oidc`; convention issuer hostname; Identity as a Workload; magic `/callback` path; client secrets / `client_credentials` for Service Network; gather-time token revocation.
