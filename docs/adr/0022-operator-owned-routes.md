# Operator-owned Routes; Setup gathers, Manifest does not project

**Refined by ADR-0040:** gathering and installing Routes into Edge interior is **Edge Component Setup** (Declaration fulfillment), not Workload Setup. Workload Setup does not write Edge interior; Edge Setup re-run after Workload Setup/Purge refreshes fulfillment (noop when unchanged). Manifest-free Route content stands.

**Amended by ADR-0043:** that refresh is Component Setup `post-workloads` (Deploy after Purge, or caller-composed outside Deploy); `pre-workloads` must not load Workload Routes that still depend on Workload Setup.

HTTP reachability for Workloads is operator-owned: Route content is native Edge config offered under Provides and bound to want-list FQDNs via Binding. Edge Component Setup gathers Intent-**run** bound Route Declarations into Edge-owned route storage, drops fulfillment for **stop** / **trash** or missing Provides/Binding, and reloads the Edge — neither Setup generates shells, proxy bodies, or Manifest **interior** splicing. Edge keeps sole :80/:443, ACME, and :80 HTTP-01 + redirect; ACME must not reproject Routes after issue/renew. Domain owns names and certificate material; ACME want-list is Domain assignment (ADR-0023); Purge deletes Workload tree and units — Edge re-gather drops fulfilled Routes; not Domains or certs. Clean break (ADR-0018): glossary, Setup, tests, and related ADRs move together; no dual-read of Manifest Route projection. **Refined by ADR-0028:** Domain fronts own per-FQDN TLS `server` blocks; Routes are Binding-attached location-context fragments included into those fronts (not competing full `server` blocks).

**Considered:** Operator edits `edge/routes/` directly with no Workload Declaration SoT (tribal ownership, weak Purge/stop reconcile); keep Manifest-projected shells + optional interior (Propraetor owns vhost behaviour); fold ACME want-list cutover into the same delivery as reachability (omnibus with #44); keep FQDN-as-filename under Workload `routes/`. Rejected for the reachability cutover / external⊂internal Artifact; want-list SoT is ADR-0023 / #44.

**Supersedes (projection / Intent-HTTP slices):** ADR-0011 (Manifest produces Routes); ADR-0012 (Setup/ACME project TLS shells); ADR-0014 Intent **stop** 503 / name-hold-as-reachability; ADR-0015 post-issue Route reprojection. ADR-0007 / ADR-0013 keep Edge + Service Network + :80 ACME/redirect / empty-Edge 404; drop Intent-aware proxy/503 prose when those ADRs are rewritten with behaviour.
