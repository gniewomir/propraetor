# Cache Component with passwordless mTLS and Valkey

Propraetor needs a shared in-memory key-value **Cache** for Workloads that must not invent per-Workload passwords or treat Service Network basename DNS as authentication, and must not accidentally collide on keys with peer Workloads. **Cache** is a mandatory public-Host Component (idle allowed with zero claimants): Valkey on the Service Network at dial name `cache` (Workload basename `cache` fail closed); Host Volume under `components/cache/` with **Persist** for Cache-owned TLS CA/server material, per-basename client certs, ACL file, and admin EnvironmentFile — not for keyspace durability. A Workload Declares need via **Requires** `"cache": true` (ADR-0053 amended). Cache Component Setup gathers Intent-**run** claims only: ensure ACL user named by basename (cert-only: enabled, `resetpass`, no passwords, no `nopass`), client cert CN=`basename`, `tls-auth-clients yes` + `tls-auth-clients-user CN`, key pattern `~basename:*`, command whitelist from `-@all` plus v1 type categories (`@string` `@hash` `@list` `@set` `@sortedset`) and `ping`, plus explicit keyspace verbs needed for cache DX (`del` `unlink` `exists` `type` `expire`/`ttl` family `persist` `touch`) — never `+@keyspace` (that category admits `SCAN`/`KEYS`/`FLUSH*`); `resetchannels`, no Workload `SELECT`; publish binding under `~/.config/platform/workloads/<basename>/cache/` (certs + `CACHE_*` env including `CACHE_KEY_PREFIX=basename:`, no password) with a Setup-owned Quadlet drop-in — Component Setup owns the projection. Intent `stop` unpublishes and disables the ACL user; **Orphan Reap** deletes the user, client material, and best-effort keys under that prefix (`post-workloads`; create/publish prefer `pre-workloads`). Keyspace is ephemeral (no AOF/RDB): loss on Component restart or Host rebuild is expected; `maxmemory` with global `allkeys-lru` eviction is accepted same-operator noisy-neighbor behavior (ADR-0034). Basenames that contain glob metacharacters `* ? [ ]` or `:` fail closed for Cache claims. Admin path is a dedicated ACL user from Environment-scoped **Cache admin credentials** (`ROOT_CACHE_USER`, `ROOT_CACHE_PASSWORD`) staged like Database admin credentials — never Binding-remapped into Workloads; ACL user `default` is `off` so unknown CN does not fall through to a usable session. Operator UI `./cache.sh` opens `valkey-cli` via SSH TCP tunnel as that admin (no read|write split in v1), presenting a Cache Persist–owned **admin client certificate** whose CN matches the admin ACL username (issued at Setup alongside the admin user) — not a Workload client cert. Product identifiers and prose lead with **Cache**; Valkey names the engine only; Redis is not used on the contract surface (dial, Requires, paths, env, CLI). In-pod Valkey/Redis-compatible processes remain Escape Hatch (ADR-0034); shared Cache is the taught path. Deferred: cert rotation UX, streams/pubsub/scripting, per-tenant memory caps, footprint knobs beyond small-Host defaults, teaching Workload for Cache. Engine floor from spike: Valkey ≥ 9.0 (`tls-auth-clients-user`); prefer `valkey/valkey:9.1-alpine`. Note: `AUTH` cannot be ACL-denied for Workload users in a way that blocks later `AUTH admin`; admin password + any CA-signed client cert yields admin — keep **Cache admin credentials** off Workload bindings.

**Amends:** ADR-0053 (Requires gains required boolean `cache` beside `database`); ADR-0035 (reserved `ROOT_CACHE_USER` / `ROOT_CACHE_PASSWORD` are Cache admin credentials — not Workload Environment Configuration); ADR-0040 / ADR-0043 (Cache is a further Declaration-fulfilling Component; fulfillment/publish in `pre-workloads`, orphan cleanup in `post-workloads`); ADR-0049 (parallel passwordless mTLS Component pattern; Cache is not Database).

**Rejected:** Redis OSS as the Component engine (AGPL/SSPL/RSAL tri-license; Valkey originated `tls-auth-clients-user`); Redis as Product/dial/Requires/env naming; capability name Valkey (engine ≠ Product — **Cache** mirrors Database/PostgreSQL); numbered logical DB per Workload as the isolation unit (finite slots, Cluster-hostile, fake-Postgres teaching); convention-only prefixes without ACL; `+@all` then blacklist for Workloads; Workload `nopass` ACL users; using ACL `default` as the admin root; optional/absent Cache Component when Requires claims `cache`; durable keyspace (AOF/RDB) as v1 SoT; `noeviction` as v1 default (global LRU chosen for honest cache semantics); Intent stop that only unpublishes while leaving the ACL user enabled; retain-keys-on-Orphan-Reap; shared CA with Database; Manifest-held Cache secrets; Operator Configuration for admin creds; dual `REDIS_*` binding aliases in v1.
