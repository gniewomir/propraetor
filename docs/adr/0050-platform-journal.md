# Platform journal: stdout/stderr only, Substrate-owned

Propraetor’s sole Host destination for Propraetor-owned unit and container **diagnostic** streams is the **Platform journal** (Platform User systemd journal). Components and Workloads must emit those streams on stdout/stderr — not application log files, and not Host Volume log mounts. Access/request streams default **off** (opt-in later). Capture is Podman `log_driver=journald` via Platform User `containers.conf`, established in **Initial Host Provisioning**. Host journald is `Storage=persistent` with explicit size caps (`SystemMaxUse=` and peers), also IHP. **IHP Done** / **Substrate** include that on-disk contract plus a small live probe (fail closed). IHP cloud-init files and SSH Setup output stay outside this policy; **Host diagnostics** does not gain a journal bundle yet — operators use the [Platform journal runbook](../runbooks/platform-journal.md). Workload “no file logs” is a documented soft contract (Workload Setup does not lint mounts).

**Rejected:** File logging under `/var/log` or Host Volume for Propraetor units; trusting Podman’s journald-or-k8s-file default without a pin; volatile-only journal store; folding journal snapshots into Host diagnostics for this decision; Setup heuristics that ban `**/log/**` binds; requiring access/request logs into the journal by default.
