# Environment Configuration reaches Workloads via EnvironmentFile

Operators need non-committed, Environment-scoped key/value configuration in Workload containers without putting secrets in the repository or substituting values into unit/config text. Research showed plain placeholder→value substitution into systemd/Quadlet grammar is unsafe for arbitrary values; Quadlet `EnvironmentFile=` (and Setup-owned drop-ins) keeps values out of unit text while Host Volume SoT stays authored Manifest + Binding + Artifact. This ADR records that contract. Glossary term: **Environment Configuration**. Manifest thinness / Source: ADR-0024 / ADR-0053. EnvironmentFile tree cleanup on Host destroy: ADR-0014 / ADR-0054 (Orphan Reap). Wayfinder map [Operator-supplied configuration for Workloads and Components](https://github.com/gniewomir/prefect/issues/106) is the decision audit trail.

**Contract (v1).** One Environment-scoped bag per Propraetor Environment. Baseline from gitignored `environments/<slug>/.env` when present; optional `environments/<slug>/.env.override` overlays on key collision; current shell overrides any key from either file; if neither file supplies a remapped key, it must come from the shell. Workload **Requires** declares process env names; **Binding** remaps bag keys onto those names (full fulfill — ADR-0053). Workload Setup materializes **only the remapped names** (Workload-facing name = Requires name; value from bag key) into **one** Platform User–local EnvironmentFile at `~/.config/platform/workloads/<basename>/environment` and wires it via Setup-owned Quadlet drop-ins (`EnvironmentFile=` on each install copy of that Workload’s `systemd/*.container`). Surplus bag keys that Binding does not remap are ignored for that Workload — not an error. Missing remapped keys fail closed in Setup. A non-empty Requires `environment` map with no `systemd/*.container` fails closed (v1 injection is Quadlet-only). Re-Setup is the rotation path: it rewrites the EnvironmentFile from current sources; empty Requires environment removes those artifacts; Workload Setup still requires ≥1 allowlisted unit in `systemd/` after projection (ADR-0054) — a zero-unit Workload is not a valid Setup path; **stop** retains Environment Configuration until **Orphan Reap**; Orphan Reap removes the EnvironmentFile tree and Setup drop-ins with the Host Workload. Values never appear in unit grammar or on the Host Volume Workload tree. Native Always-on `.service` units are out of v1 for this path. **Workloads only** — Components neither declare nor receive EnvironmentFiles in v1. `ROOT_DB_USER` / `ROOT_DB_PASSWORD` may share `environments/<slug>/.env` (and `.env.override`) but are **Database admin credentials**, not this Workload bag — ensure-components stages them for Database; Binding must not remap them into Workloads (fail closed) (ADR-0049). **Provider Credential** and **Operator Configuration** stay orthogonal — their baseline file is repo-root `.env` ([ADR-0038](0038-repo-root-operator-dotenv.md)), not this bag.

**Operator file conventions.** Strict dotenv subset for `.env` and `.env.override` (`KEY=value`, `#`/blanks, optional double quotes; no `export`, interpolation, or multiline). Load paths are exact `environments/<slug>/.env` then optional `.env.override` (override wins on collision); never-commit / agent-ignore for any `**/.env*` (sole exception: basename `.env.example`) is [ADR-0048](0048-env-star-commit-and-agent-ignore.md). Required committed `.env.example` per operator-facing Environment (Setup does not read it). Key names are operator-owned — Setup does not reserve or reject names — but prefer not to use `PLATFORM_*` or Provider Credential names as Binding remaps or in `.env.example`. Precedence: shell > `.env.override` > `.env`.

**Rejected:** plain textual substitution / placeholders for this path; bag values in `Environment=` or other unit grammar; Host Volume as the value store; Host vaults / cloud secret managers; folding Credential into the bag; Component EnvironmentFiles in v1; Setup reserved-name enforcement; live reload or a separate rotate command without Setup; Manifest `environment[]` (retired — ADR-0053).

**Deferred to `/to-spec` / implementation planning (not this ADR):** drop-in basenames, Setup script module layout, parser internals, operator-facing rotation UX beyond re-Setup rewrite, CI shell-only ergonomics, and when Components might later consume the bag.
