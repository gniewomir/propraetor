# Domain fronts own TLS servers; Workload Routes are FQDN-keyed fragments

Edge HTTPS for Domain want-list names is Edge-owned: Edge Setup reconciles stable **Domain front** drop-ins under `data/components/edge/domains/` (`<fqdn>.conf`), mounted at `/etc/nginx/edge-domains`, separate from Workload `routes/`. Shape SoT is Edge Component `domain-template.conf` (missing template fails closed); Setup renders want-list FQDNs into those drop-ins. Each Domain front is the TLS `server` for that FQDN; ACME replaces PEM bytes only and never mutates drop-ins. The Domain front — not Workload Routes — owns Edge baseline `/healthcheck` (`200`, `text/plain`, `ok`) and the per-name `:80`→HTTPS redirect for non-ACME paths (ADR-0013); zero Workloads still leaves that baseline. Workload **Routes** stay operator-authored and Manifest-free (ADR-0022 / ADR-0024), but on Propraetor they are **server-context snippets** named `<fqdn>.conf` whose SoT is Workload Host Volume `routes/`; **Edge Component Setup** gathers Intent-**run** Declarations and fulfills them as `<workload>--<fqdn>.conf` into Edge `routes/`, pulled in with `include /etc/nginx/edge-routes/*--<fqdn>.conf;` inside that Domain front’s HTTPS server — not competing full `server` blocks and not via a top-level `edge-routes/*.conf` include. Setup fails closed if a Route basename is not on the want-list (validated before mutating installs). Empty nginx wildcard includes are valid when the parent directory exists — no `00-empty` stubs. Full portable Workload `server` blocks were rejected: TLS for Domain names belongs to the Edge, and associating fragments via filename keeps the Manifest thin. Residual Domain fronts only for “unclaimed” names were rejected: split HTTPS ownership. Literal nginx listen/`ssl_*` lines remain an implementation detail so long as cert paths stay the stable `certs/<fqdn>/` pair (ADR-0029) and the baseline behaviour holds.

**Refines:** ADR-0022 (operator-owned Routes remain SoT and non-projected; shape is FQDN-keyed server-context, not a full TLS `server`). **Builds on:** ADR-0010 (Host Volume layout), ADR-0015 / ADR-0023 (Edge ACME + Domain want-list), ADR-0029 (placeholder PEMs).
