# Domain fronts own TLS servers; Workload Routes are Binding-attached fragments

Edge HTTPS for Domain want-list names is Edge-owned: Edge Setup reconciles stable **Domain front** drop-ins under `data/components/edge/domains/` (`<fqdn>.conf`), mounted at `/etc/nginx/edge-domains`, separate from Workload Artifact trees. Shape SoT is Edge Component `domain-template.conf` (missing template fails closed); Setup renders want-list FQDNs into those drop-ins. Each Domain front is the TLS `server` for that FQDN; ACME replaces PEM bytes only and never mutates drop-ins. The Domain front — not Workload Routes — owns Edge baseline `/healthcheck` (`200`, `text/plain`, `ok`) and the per-name `:80`→HTTPS redirect for non-ACME paths (ADR-0013); zero Workloads still leaves that baseline. Workload **Routes** stay operator-authored and Manifest-free (ADR-0022 / ADR-0024), but on Propraetor they are **location-context fragments** listed under **Provides** and attached to FQDNs only via **Binding**; **Edge Component Setup** gathers Intent-**run** Declarations and fulfills them into Edge-owned route storage included inside that Domain front’s HTTPS server — not competing full `server` blocks. Setup fails closed if a Binding FQDN is not on the want-list, or if Provides/Binding fulfillment rules fail (ADR-0053). Empty nginx wildcard includes are valid when the parent directory exists — no `00-empty` stubs. Full portable Workload `server` blocks were rejected: TLS for Domain names belongs to the Edge. FQDN-as-filename under Workload `routes/` was rejected: external Artifacts must not encode Propraetor FQDNs (ADR-0053). Residual Domain fronts only for “unclaimed” names were rejected: split HTTPS ownership. Literal nginx listen/`ssl_*` lines remain an implementation detail so long as cert paths stay the stable `certs/<fqdn>/` pair (ADR-0029) and the baseline behaviour holds.

**Refines:** ADR-0022 (operator-owned Routes remain non-projected; shape is Binding-attached location-context, not a full TLS `server`). **Builds on:** ADR-0010 (Host Volume layout), ADR-0015 / ADR-0023 (Edge ACME + Domain want-list), ADR-0029 (placeholder PEMs).
