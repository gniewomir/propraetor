# Deploy, Mirror, Orphan Reap, and Host Volume layout

Propraetor gains **Deploy** — root `deploy.sh` takes a **Substrate** Host to **Deployed** without running Stack **Apply**. Internals compose the ladder; day-to-day truth is `CONTEXT.md`.

**Deploy ladder:** **Fabric Setup** → **Mirror** → **Orphan Reap** → **Component Setup** (`pre-workloads`) → **Workload Setup** (every Environment Workload) → **Purge** → **Component Setup** (`post-workloads`). Scripts: `ensure-fabric` → `ensure-mirror` → `purge-orphans` → `ensure-components pre-workloads` → `ensure-workloads` → `purge-trash` → `ensure-components post-workloads` (plus singular `ensure-workload`, orchestrator `ensure.sh`). Every Component ships both slot scripts; there is no single-shot `full` mode (ADR-0043). Discover Workloads under `environments/<slug>/` as immediate non-hidden directories (ADR-0033; Manifest gate retired by ADR-0047). **Mirror** materializes each Environment Workload onto Host Volume `internals/workloads/<basename>/` **regardless of Source** (Environment tree upsert + resolve Source + apply Provides directories — ADR-0053); leaves orphans alone. **Orphan Reap** removes Host Workloads absent from the Environment (volume trees + units + EnvironmentFiles). **Purge** remains Intent-**trash** only (names still in the Environment). Orphan Reap runs before `pre-workloads` so Edge gather does not fulfill orphan Intent-**run** Routes. Do not wipe-replace all of Host `internals/` while live Components bind-mount source files (e.g. Edge `nginx.conf`); Fabric/Component trees ship via their ensure scripts with non-breaking update semantics. Mirror does not replace whole `internals/`.

**Host Volume:** `/var/lib/host-volume/internals/{fabric,components,workloads,host-scripts}` and `/var/lib/host-volume/data/{fabric,components,workloads}`. Bound Route **fulfillment** and Domain fronts/certs/ACME live under `data/components/` (Edge-owned; ADR-0028 / ADR-0053). Workload durable bytes that must survive Mirror live under `data/workloads/<name>/`. Repo `internals/lib/` is **operator-machine** shared code only; Host-executable helpers live in repo `internals/host-scripts/` (+ `lib/`) and ship to Host Volume `internals/host-scripts/`. Repo also splits `internals/fabric/` from `internals/components/` (Service Network is not a Component path).

**Amends:** ADR-0010 (retires `components/` + `components_data/` Host Volume layout and combined ensure-components-as-Fabric+Component ship story); ADR-0014 (Purge stays trash-only; Orphan Reap is the Environment-absence destroy path); ADR-0032 (`deploy.sh` is the root composition entrypoint foreshadowed there; internals cogs renamed/split as above; `host-scripts` vs operator `lib/`); ADR-0033 (Environment absence is Orphan Reap, not deferred operator risk; Host Volume SoT vs `data/` split); ADR-0034 (Workload owns `internals/` + `data/` trees under the basename); ADR-0040 (Deploy places Mirror before the first Component Setup slot so gather sees Environment SoT).

**Rejected:** Expanding Fabric to include Environment mirror; repo-as-SoT for Edge gather; Mirror wipe-and-refill of all `internals/` (breaks live bind mounts); Mirror drop-cleanup conflated with Purge; Purge overloaded to mean orphan reap; Deploy that runs Apply; `ensure-workloads` without a singular `ensure-workload`; garbage-collector as the domain name for Purge.

**Cutover:** glossary updated; Host Volume layout hard cut implemented in #154; `ensure-fabric` / `ensure-components` split in #155; Mirror + Orphan Reap in #156; `ensure-workload(s)` / `purge-trash` in #157; Deploy ladder / `ensure.sh` / `deploy.sh` in #158.
