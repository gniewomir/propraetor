# Deploy, Mirror, Orphan Reap, and Host Volume layout

Propraetor gains **Deploy** — root `deploy.sh` takes a **Substrate** Host to **Deployed** without running Stack **Apply**. Internals compose the ladder; day-to-day truth is `CONTEXT.md`.

**Deploy ladder:** **Fabric Setup** → **Mirror** → **Orphan Reap** → **Component Setup** (`pre-workloads`) → **Workload Setup** (every Environment Workload) → **Component Setup** (`post-workloads`). Scripts: `ensure-fabric` → `ensure-mirror` → `purge-orphans` → `ensure-components pre-workloads` → `ensure-workloads` → `ensure-components post-workloads` (plus singular `ensure-workload`, orchestrator `ensure.sh`). Every Component ships both slot scripts; there is no single-shot `full` mode (ADR-0043). Discover Workloads under `environments/<slug>/` as immediate non-hidden directories (ADR-0033; Manifest gate retired by ADR-0047). **Mirror** materializes each Environment Workload onto Host Volume `workloads/<basename>/` **regardless of Source** (Environment tree upsert + resolve Source + apply Provides directories — ADR-0053); leaves orphans alone. **Orphan Reap** removes Host Workloads absent from the Environment (volume trees including Persist, units, EnvironmentFiles) — the sole supported Host Workload destroy path. Orphan Reap runs before `pre-workloads` so Edge gather does not fulfill orphan Intent-**run** Routes. Do not wipe-replace all of Host owner trees while live Components bind-mount source files (e.g. Edge `nginx.conf`); Fabric/Component trees ship via their ensure scripts with non-breaking update semantics. Mirror does not replace whole Host Volume.

**Host Volume:** mount `/host-volume` with owner trees `fabric/`, `components/<name>/`, `workloads/<basename>/`, `host-scripts/` and nested **Persist** for Workloads/Components (ADR-0054). Bound Route **fulfillment** and Domain fronts/certs/ACME live under Edge Persist. Repo `internals/lib/` is **operator-machine** shared code only; Host-executable helpers live in repo `internals/host-scripts/` (+ `lib/`) and ship to Host Volume `host-scripts/`. Repo also splits `internals/fabric/` from `internals/components/` (Service Network is not a Component path).

**Amends:** ADR-0010 (retires `components/` + `components_data/` Host Volume layout and combined ensure-components-as-Fabric+Component ship story); ADR-0014 (Orphan Reap is the Environment-absence destroy path); ADR-0032 (`deploy.sh` is the root composition entrypoint foreshadowed there; internals cogs renamed/split as above; `host-scripts` vs operator `lib/`); ADR-0033 (Environment absence is Orphan Reap, not deferred operator risk); ADR-0034 (Workload owns Host Volume tree under the basename); ADR-0040 (Deploy places Mirror before the first Component Setup slot so gather sees Environment SoT).

**Rejected:** Expanding Fabric to include Environment mirror; repo-as-SoT for Edge gather; Mirror wipe-and-refill of all Host Volume; Mirror drop-cleanup conflated with destroy; Orphan Reap overloaded as Intent destroy; Deploy that runs Apply; `ensure-workloads` without a singular `ensure-workload`.

**Cutover:** glossary updated; Host Volume layout hard cut implemented in #154; `ensure-fabric` / `ensure-components` split in #155; Mirror + Orphan Reap in #156; `ensure-workload(s)` in #157; Deploy ladder / `ensure.sh` / `deploy.sh` in #158.

**Amended by ADR-0054 / #215 / #217:** mount `/host-volume` + nested Persist; Intent **run**|**stop** only; Purge / Intent **trash** / `purge-trash` retired — Deploy ladder has no Purge step.
