# Fabric, Component, Workload, and Declarations

Propraetor’s Host-side ladder is **Substrate** → **Fabric** → **Component** → **Workload**. **Substrate** is the Host condition after IHP Done — everything required to run Fabric Setup (today: engine, Platform User, ports, Host Volume mount); not a Setup kind and not a peer of Fabric/Component/Workload. **Fabric** is the post-Substrate layer Components and Workloads require (today: Service Network only); **Fabric Setup** applies Fabric; IHP produces Substrate (including the mount) and is not Fabric. **Component** owns a shared resource and fulfills **Declarations** from agreed SoT (Workload Provides/Requires resolved via Binding and/or Environment config); no Workload Intent; Workload Setup does not perform Component fulfillment. **Workload** combines Artifact + Manifest + Binding, declares Intent, and may author Declarations; does not gather peers. **Declaration** is a statement of what a Workload Provides or Requires, or an Environment-authored claim (today: Domain assignment into Edge); Binding may resolve Workload Declarations; Components may gather the subset they fulfill (bound Routes → Edge; Requires `database` → Database; Domain assignment → Edge). **Edge** and **Database** are mandatory Components on public Hosts (product bits). Bound Route Declarations are fulfilled into Edge-owned storage; **Edge Component Setup** gathers Intent-**run** Routes in the `post-workloads` slot after Workload Setup or Purge (noop when unchanged); `pre-workloads` must not load Workload Routes that still depend on Workload Setup (ADR-0043). **Deploy** runs **Mirror** (and **Orphan Reap**) before the first Component Setup slot so gather sees Environment Workload SoT (ADR-0041); Host Volume paths and ensure packaging follow ADR-0041. Day-to-day truth: `CONTEXT.md`.

**Amends:** ADR-0007 (Service Network is Fabric, not a Component peer of Edge); ADR-0010 (ensure path must distinguish Fabric Setup from Component Setup; network is not a Component); ADR-0022 (Setup that gathers Routes is Edge Component Setup — not Workload Setup installing into Edge). Operator-authored Route content and Manifest-free projection stay as in ADR-0022 / ADR-0053.

**Rejected:** Collapsing Component and Workload into one kind; Workload Intent on Components; keeping Route fulfillment in Workload Setup; defining Fabric as “everything IHP does”; putting the Host Volume mount in Fabric; collapsing Substrate into Fabric or into the IHP Done gate.

**Amended by ADR-0055:** Cache is a further Declaration-fulfilling Component (Requires `cache`).

**Amended by ADR-0057:** Identity is a further Declaration-fulfilling Component (Requires `identity`; Service Network dial name `identity`; issuer hostname declared in `identity.json`; Edge owns that FQDN's Domain front proxy and fails closed on Workload Route collisions).
